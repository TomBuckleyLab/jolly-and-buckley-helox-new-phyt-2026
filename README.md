# jolly-and-buckley-helox-new-phyt-2026
Code, sample data and processed data for Jolly and Buckley (2026, New Phytologist)

Paper describing helox method for measuring relative humidity of intercellular airspaces in leaves.

Included in this repository:
 - sample data.csv: sample data from one experimental day, with six nitox-to-helox switches
 - jolly and buckley (helox) code.R: code to calculate intercellular humidity and associated parameters from data organized as in sample data.csv
 - jolly and buckley (helox) processed results.csv: data underlying all experimental results presented in the paper
